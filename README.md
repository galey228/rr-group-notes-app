Прототип приложения «Заметки РР-Групп»

Кейс-задача № 5. Отчет по практике: Юзабилити-тестирование приложения «Заметки РР-Групп»
Кейс-задача № 4. Приложение для ведения заметок с графическим интерфейсом.

 Функции
- Создание, редактирование, удаление, поиск заметок
- Два хранилища: SQLite (`notes.db`) и файловая система (`notes_files/*.json`)
- Кроссплатформенность (Windows / macOS / Linux)

Технологии
Python 3.15, Tkinter (GUI), sqlite3, json.

Как запустить
1. Скачать репозиторий (Code → Download ZIP) и распаковать.
2. Открыть терминал в папке проекта.
3. Выполнить: `python notes_app.py`
4. Сторонние библиотеки не требуются.

 Файлы
- `notes_app.py` — рабочая версия на Tkinter
- `main.py` + `notes.kv` — альтернативная версия на KivyMD (не запущена из-за несовместимости с Python 3.15)
- `notes.db` — база данных SQLite
- `notes_files/` — пример заметок в JSON
